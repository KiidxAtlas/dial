# Terminal interface

Everyday use of the interactive terminal UI: composer, slash commands, shortcuts, settings panels, model settings, themes and previews. Rendering internals are described in [tui-rendering.md](tui-rendering.md).

Start with [Everyday Dial](everyday.md), or choose a focused reference below.

- [Composer and transcript](terminal-composer.md): Write, paste and edit drafts without losing your place; understand the launch screen, transcript and status line.
- [Commands and help](terminal-commands.md): Find actions through the goal-first palette, slash completion and command help.
- [Keyboard shortcuts](terminal-shortcuts.md): Find the active keys, edit bindings and handle terminal-specific keyboard differences.
- [Sessions and history](terminal-sessions.md): Resume, search, branch, share and move conversations while preserving their recorded history.
- [Models and roles](terminal-models.md): Keep model selection, roles, favorites, downloads and per-model tuning together in the Models panel.
- [Terminal settings](terminal-settings.md): Search configuration, choose storage scope and review setup presets before saving.
- [Terminal integration](terminal-integration.md): Use terminal links, titles, progress signals and the optional live side pane.
- [Turns, steering and review](terminal-turns.md): Steer running work, queue follow-ups and review recorded outcomes without confusing history with fresh verification.

Use `/help <topic>` for a documentation path and introduction. `/help` opens the action
palette; `/help text` and `/help all` print command lists. [All documentation](README.md).
