# Focused macOS Rust contract, run by `scripts/windows-contract.py --contract` on the macOS runner.
#
# The full portable suite runs on Linux. macOS runs the modules whose behavior differs on macOS:
# each filter below owns code under `cfg(target_os = "macos")` or a macOS-specific backend
# (Seatbelt sandbox, APFS clones, power assertions, launchd scheduling, pasteboard, keychain and
# browser discovery). Add a filter when adding macOS-specific code; remove one only with its code.
# `make preflight` on a macOS host still runs the full suite before pushing.
#
#   test-lib <package> <libtest-filter>              explicit package library (substring match)
#   test-bin <package> <binary> <filter>             explicit binary target (substring match)
#   test-integration <package> <target> <filter>     explicit integration-test target
#   skip <test-path> # <reason>                      excluded via libtest `--skip`
